# ahetru.github.io

Personal website of Axel Hetru, in English (`/en/`) and French (`/fr/`).

Plain HTML, CSS and a little JavaScript, no build step. The site lives in `docs/`. To preview locally:

```sh
python3 -m http.server 8000 -d docs
```

then open http://localhost:8000/en/. GitHub Pages serves `docs/` from the `main` branch.
