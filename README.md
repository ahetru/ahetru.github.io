# ahetru.github.io

Personal website of Axel Hetru, in English (`/en/`) and French (`/fr/`).

Plain HTML, CSS and a little JavaScript, no build step. The site lives in `site/`. To preview locally:

```sh
python3 -m http.server 8000 -d site
```

then open http://localhost:8000/en/. Pushing to `main` deploys to GitHub Pages.
